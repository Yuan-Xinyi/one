# 论文新框架提案(按 paper.md 发布会原则)

## 本文的发布点(唯一主线)

**新问题 + 可证量化 + 免训练解法。**
点到点可达性回答不了"一条连续关节轨迹能沿路径执行多远"。本文
①把这个执行长度(行程)本身定义为优化目标(exit-time 最优控制);
②给出逐任务的双侧夹逼——逐点 IK 上界 + 系统实现下界——首次量化
pointwise 可达与连续可执行之间的差距;
③给出一个两段式系统吃掉这个差距的大部分:可学习的初始构型 selector
(标签由解析控制律免费生成)+ 由 HJB 结构推出的解析极点控制律
(零训练、零调参迁移到三种构型不同的机械臂);
④给出"分辨率解离"设计定律:状态间的价值差可学、状态内的动作差
应解析,用受控实验钉死学习该放在哪一层。

RL 在论文中的角色(用户定夺 2026-08-11):**仅作为 baseline 对比,
不承担任何叙事责任**。阶梯表里的普通行,与 classical 同级;顶点动作集
的合理性由 Prop 1(理论)与解析律的表现(实验)支撑,不引用训练曲线;
精确优化平台的探针只用 beam/CEM(解析工具)。表述一律用"learned
policy over an HJB-motivated value-preserving vertex action set";
不出现"失败/未能超过"类叙述,不单列失败清单。

## 章节框架

### I. Introduction
0. **Fig. 1 = 开门动机图**(figures/fig_door_opening.py,用户 2026-08-11
   定稿):同一扇门、同一条把手路径、每个路径点都逐点可达;
   (a) 选对初始构型 + 选对冗余消解 → 整扇门扫完;
   (b) 两个不佳的初始关节构型 → 行程早停;
   (c) 两个不佳的冗余消解方法 → 行程早停。
   图注即论文论点:结局不由"可达性"决定,而由两个自由度决定——
   初始构型的选择(→ 本文第一段 selector)与逐时刻的冗余消解
   (→ 本文第二段解析边际律)。一张图预告全部方法结构。
1. 开场即问题:焊缝/开门——每个路径点都"可达",一条连续轨迹却走不完。
   行程(单次连续执行的路径长度)是真正的工程量,却没有人量化它。
2. 缺口:可达图回答逐点存在性;全局冗余消解回答连续 IK 映射的存在性;
   都不回答"能连续走多长",更没有逐任务可证的界。
3. 本文方案与最有分量的数字:双侧夹逼 + 两段式系统实现认证上界的 X%
   (E1 定稿后填),三臂零调参复现。
4. 贡献四条 = 上面 ①②③④。

### IV. HJB Structure and Vertex-Valued Feedback(保留 + 升格)

- IV-C 从"与经典律的关系"升格为**解析边际律的推导**:

### V. Extreme Motion Generation(两段式系统)
- V-A Initial-configuration selector:CVT 表候选生成(锥内方向 ×
  温启动投影 × 最远点筛选)、路表条件化(前方 1.2 m 的位置/切向/锥轴
  采样)、标签 = 解析控制律 rollout(免训练、免人工标注,成本一句话)。
- V-B 解析极点控制器:顶点动作集 + 边际律;查询成本。
- V-C 分层依据:分辨率解离——选择消费状态间价值差(可学,R² 0.91),
  控制消费状态内动作差(Δmargin 0.005–0.02,低于网络分辨率,解析可得)。
  正面表述:两个尺度相差一个数量级,学习放在它有分辨率的那一层。

### VI. Experiments(每个实验一个职责)
- **E1 主结果(双侧夹逼)**:10k 任务 × 3 臂,上界 L_hi、系统实现、
  实现比;证明系统接近认证上界。视觉中心 = 这张表。
- **E2 控制器阶梯**:zero → classical → 解析边际律 → 精确优化
  (beam/CEM)平台。职责:证明解析律已坐在精确优化平台上
  (额外视野增益 ~0),优势来自正确的标量场。RL(vertex /
  continuous PPO)作为 baseline 行列入同一张表,不另行讨论。
- **E3 selector 泛化(今晚 OOD 数据)**:4 族 × {路表条件化 / 无条件 /
  出题构型},capture / regret / Spearman。职责:证明 selector 读路径
  且跨族泛化。
- **E4 跨臂复现**:fr3/xarm7/cobotta 零调参。职责:排除"FR3 特调"。
- **E5 分辨率解离(机理)**:价值回归 R² 与动作差尺度的测量,加一行
  受控探针汇总(γ、shaping、监督分类等归入附录一表)。职责:排除
  "该端到端学控制器"的替代解释,论证分层是结构必然。
- **E6 Real-world validation**(保留)。
- 删/降级:γ sweep、shaping sweep、prior-anchor 明细 → 附录一张
  汇总表;正文不再单列,不写过程叙事。

### VII. Conclusions
记忆点三句:定义并量化了连续运动可达性(带可证夹逼);给出免训练
控制律 + 可学 selector 的两段式系统,三臂迁移;确立了学习在该问题中
的正确位置(选择层)。不新增局限性讨论。
