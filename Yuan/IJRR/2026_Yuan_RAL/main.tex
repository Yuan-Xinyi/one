\begin{abstract}
This work studies \textit{extreme motion generation}, which aims to maximize the Cartesian path length that a manipulator executes along a prescribed path. Conventional reachability analysis indicates whether each point of a path is attainable. However, it does not indicate how far a \emph{single continuous joint trajectory} can carry the tool before a joint limit, an orientation tolerance, or a collision terminates the motion, and the two quantities differ substantially. We quantify the realizable part as \textit{continuous kinematic reachability} and bracket it per task between a numerical pointwise-reachability estimate and the executed stroke. \new{To realize a large fraction of the bracket, we formulate stroke maximization as a discounted exit-time optimal control problem and show that the pointwise Hamiltonian maximization is attained on the vertices of the null-space command box, so every deployed controller switches among vertex commands according to a scalar field of the configuration. A training-free constraint-margin field already matches receding-horizon optimization of its own objective, and the critic of a standard reinforcement-learning run further improves the executed stroke at identical per-step computation, whereas the policy head of the same run remains far below its own critic consumed in this way. The initial configuration is chosen by a learned selector supervised by rollouts of the deployed controller.} We evaluate the proposed framework on three manipulators with 10,000 path-following simulation tasks each, together with real-world validations, and further show that the same measurement provides a task-aware reference for manipulator base placement.

\end{abstract}

\section{Introduction}




\IEEEPARstart{C}{onsider} a compact, fixed-base manipulator executing a coating or welding operation over a large work surface. Intuition would suggest that the farthest reachable point is determined by the reachable workspace. In practice, however, the motion is continuous, and one of the safety constraints, such as joint limits, tool-orientation tolerance, or collision, is violated long before the end-effector approaches the workspace boundary. Consequently, the achievable path length is decided by how long those boundaries can be deferred during execution. We refer to the problem of maximizing the Cartesian path length along a prescribed path as \textit{extreme motion generation}. This is particularly important in industrial automation, where the length of a single continuous motion directly limits the area a manipulator can process in one setup. Rather than scaling up the manipulator or repeatedly relocating the base, exploiting the extreme motion enlarges the effective working range\footnote{The project website and related videos of this paper can be found at \url{https://yuan-xinyi.github.io/extreme-motion-generation/}.}.

\item \new{We formulate stroke maximization as a discounted exit-time optimal control problem whose HJB Hamiltonian is affine in the box-bounded null-space command. \item \new{We develop a two-sided numerical bracket of continuous kinematic reachability. A best-of-$K$ reference is not sound, as achieved strokes are observed to exceed it. The same inexpensive query also corrects a systematic optimism in reachability-map-based base placement.}
\item \new{We design a learned selector for the initial branch, the one decision a resolution law cannot make. Every candidate is rolled out under the deployed law, the outcomes serve as the labels, and a permutation-equivariant selector conditioned on a sampled table of the path ahead chooses in one forward pass. \subsection{Local Dexterity, Reachability, and Global Resolution}
Manipulability characterizes local dexterity through the
Jacobian~\cite{yoshikawa1985manipulability,yoshikawa1985dynamic,chiu1988task,klein1987dexterity}
and has been folded into null-space
resolution~\cite{liegeois1977automatic,jin2017manipulability,jaquier2021geometry,haviland2021neo}
and planning~\cite{shen2023adaptive,cai2025just}; workspace reachability
characterizes global feasibility through capability
maps~\cite{yang2009placement,zacharias2007capturing} used for base
placement~\cite{makhal2018reuleaux,vahrenkamp2013robot} and learned
priors~\cite{feng2025predictive,jauhri2022robot,selim2022safe}. Neither
indicates how joint motion should be coordinated so that a single
continuous path approaches the reachable boundary. Closer to that
question, the global structure of the solution set is well understood:
redundant IK solutions form disjoint self-motion
manifolds~\cite{burdick1989inverse}, joint limits split them into
disconnected branches~\cite{shimizu2008analytical,luck1993self}, and
global resolution has been posed as continuous
pseudoinversion~\cite{hauser2018global} or dynamic programming across
homotopy classes~\cite{ferrentino2020optimal,ferrentino2021globally,fabregat2025topological};
extremal solutions are globally optimal within their own
class~\cite{martin1989resolution,suh1987local,kazerounian1988global}.
These works treat the Cartesian path as given and ask how to execute it
optimally. They do not ask how far the path can be extended, nor how much
of the achievable extent is decided by the branch as against the law
applied within it, measured over a distribution of tasks. Learning-based
resolution~\cite{malik2022deep} and generative IK
solvers~\cite{ames2022ikflow,zhang2025ikdiffuser,huang2024diffusionseeder,yoon2023learning}
model the multiplicity of solutions but are likewise evaluated on how
well a prescribed path is executed. In contrast, this paper assigns
learning to state-level judgments (branch selection and successor
evaluation) and the exact model to action-level distinctions; learned
reactive policies are evaluated as baselines under identical conditions.

\subsection{\new{Quantifying Continuous Reachability}}
\new{Two lines of work are closely related to this measurement, and we
state the differences explicitly. The first line asks whether a
prescribed path can be executed at all by one continuous joint
trajectory, including the hierarchy of pointwise, pathwise and global
resolution~\cite{hauser2016continuous}, paths whose waypoints are
individually reachable while no continuous resolution
exists~\cite{hauser2018global}, and the $t$-connected regions of the
cuspidal literature~\cite{wenger1991uniqueness,wenger2023cuspidal,elias2025cuspidal}.
These are set-valued or binary statements. The second line counts interruptions when a
path cannot be covered entirely, minimizing reconfigurations or
breakpoints~\cite{wang2024iklink,yang2022optimal,yin2024breakpoints}.
However, a count yields no arc length and no upper reference, and by
permitting reconfiguration it cannot ask how far a \emph{single} stroke
reaches. Closest in spirit, Gautier et al.~\cite{gautier2024comparison}
reported maximum weldable extents along prescribed trajectories, but as
case-study numbers for a non-redundant arm, which are one-sided by
construction. Therefore, a per-task, two-sided, distribution-level
measurement, together with the attribution of the measured extent to the
choices that produce it, is still missing; supplying it is one goal of
this paper.}

\section{Problem Formulation}
While extreme motion generation applies broadly to constrained path following, we here specify it as extreme straight-line path following. Specifically, a fixed-base manipulator advances its end-effector along the line with a tool-orientation constraint. Solving it requires choosing the initial joint configuration and then generating the motion that maximizes the achievable path length.



Formally, consider a manipulator with $n$ degrees of freedom, where $\mathbf{q} \in \mathbb{R}^{n}$ denotes the joint configuration. Let $\mathbf{p}(\mathbf{q}) \in \mathbb{R}^{3}$ denote the end-effector position and $\mathbf{z}(\mathbf{q}) \in \mathbb{R}^{3}$ denote the TCP local $z$-axis. A straight-line path-following task is specified by the condition vector $\mathbf{c} = [\mathbf{p}_{0}, \mathbf{d}, \mathbf{n}] \in \mathbb{R}^{9}$, where $\mathbf{p}_{0}$ is the starting position and $\mathbf{d}$, $\mathbf{n}$ are unit vectors giving the motion direction and task-plane normal. \new{The prescribed path is the ray $\mathcal{P}=\{\mathbf{p}_{0}+s\,\mathbf{d} : s\ge 0\}$, along which the end-effector advances at a commanded speed $v$, one command being issued per control period $\Delta t$.} \new{The straight ray is the default member of a family sharing this condition vector: a signed curvature bends it into an arc, a sinusoidal lateral offset turns it into a serpentine seam, and a rotating cone axis $\mathbf{n}(s)$ models a non-planar workpiece. All four families are evaluated in Section~\ref{sec:setup}; the formulation carries over with $\mathbf{d}$ read as the instantaneous tangent and $\mathbf{n}$ as the local cone axis.\xinyi{这里说直线的表述可以扩充到曲线，然后如何扩充的讲一下，就行了。不需要说all four什么的，这里只是构造问题。}}

Starting from an initial configuration $\mathbf{q}_{0}^{*}$, the policy $\pi$ chooses the joint motion at every control step, producing a joint trajectory that ends at step $T$, when a safety constraint is first violated. \new{The executed motion is a \emph{stroke} of Cartesian length $\mathcal{L}$.} The task is the constrained optimization problem:
\begin{align}
\max_{\mathbf{q}_{0}^{*},\,\pi} \quad & \mathcal{L}(\mathbf{q}^{*}_{0},\,\pi;\,\mathbf{p}_{0}, \mathbf{d}, \mathbf{n}) \\
\text{s.t.} \quad & {\color{red}\operatorname{dist}\bigl(\mathbf{p}(\mathbf{q}_{t}^{*}),\,\mathcal{P}\bigr) \leq \epsilon_{\text{pos}}}, \label{eq:pos_constraint} \\
& \arccos\!\left( \mathbf{z}(\mathbf{q}_{t}^{*})^{\top} \mathbf{n} \right) \leq \theta_{\max}, \label{eq:ori_constraint} \\
& \mathbf{q}_{\min} \preceq \mathbf{q}_{t}^{*} \preceq \mathbf{q}_{\max}, \label{eq:jl_constraint}
\end{align}
where $\mathcal{L}$ denotes the stroke length, $\mathbf{q}_0^*$ and $\pi$ are the initial configuration and the control policy to be optimized, and $(\mathbf{p}_0, \mathbf{d}, \mathbf{n})$ specify the task conditions as above. The $\epsilon_{\text{pos}}$, $\theta_{\max}$, and $[\mathbf{q}_{\min}, \mathbf{q}_{\max}]$ are the position tolerance, orientation tolerance, and joint limits, respectively.

Since only the $3$-DoF position must be tracked, the manipulator is kinematically redundant for $n>3$, and the commanded joint velocity decomposes into a task term and a null-space term,
\begin{equation}
\label{eq:nullspace}
{\color{red}
\dot{\mathbf{q}} = \mathbf{J}^{+}_{\lambda}\dot{\mathbf{x}} + \mathbf{B}(\mathbf{q})\,\mathbf{u},
\qquad
\mathbf{J}\mathbf{B}=\mathbf{0},\quad
\mathbf{B}^{\!\top}\mathbf{B}=\mathbf{I},}
\end{equation}
\new{where $\mathbf{J}^{+}_{\lambda}$ is the damped pseudo-inverse of the
position Jacobian and $\mathbf{B}(\mathbf{q})$ an orthonormal basis of its
\emph{exact} null space (double-precision SVD; task-aligned construction in
Section~\ref{sec:traj}), so $\mathbf{J}\mathbf{B}=\mathbf{0}$ holds by
construction and the secondary motion cannot disturb the end-effector
regardless of the damping; $\mathbf{u}$ collects the null-space coordinates.}
Within this null space the classical law performs gradient ascent on a
weighted secondary field,
\begin{equation}
\label{eq:secondary}
\boldsymbol{\xi}=k_{\mu}\,\nabla_{\mathbf{q}}w_{\mathbf{d}}(\mathbf{q})\;-\;k_{\mathrm{jl}}\,\frac{\mathbf{q}-\mathbf{q}_{\mathrm{mid}}}{\mathbf{q}_{\max}-\mathbf{q}_{\min}}\;+\;k_{\theta}\,g(\theta)\,\nabla_{\mathbf{q}}\!\big(\mathbf{z}(\mathbf{q})^{\top}\mathbf{n}\big),
\end{equation}
where the secondary field $\boldsymbol{\xi}$ combines a directional-manipulability term $w_{\mathbf{d}}$ that retreats from singularities along $\mathbf{d}$, a centering term that pulls each joint toward the middle $\mathbf{q}_{\mathrm{mid}}$ of its range, and a cone term gated by $g(\theta)$ that activates only as the tool axis approaches the $\theta_{\max}$ boundary. \new{It enters the decomposition as $\mathbf{u}\propto\mathbf{B}^{\!\top}\boldsymbol{\xi}$; all controllers share Eq.~(\ref{eq:nullspace}) and differ only in how $\mathbf{u}$ is generated.}

{\color{red}
Note that the horizon of this problem is not given in advance: the stroke ends at the first constraint violation, and the time at which this happens is itself determined by the commands being optimized. The next section casts the objective as a discounted \emph{exit-time} optimal control problem and derives the proposed resolution laws from it.\xinyi{这段可以不要吧感觉。}

$m=3$ for Cobotta). Under this bound the decomposition of
Eq.~(\ref{eq:nullspace}) is control-affine,\xinyi{注意到其实这里和上面的problem formulation是同一个叙述模式，完全可以把共通的放在一起。这样也不需要在括号里面讲零空间自由度。}
\begin{equation}
\label{eq:affine}
\dot{\mathbf{q}} \;=\; \mathbf{f}(\mathbf{q}) \;+\; \mathbf{G}(\mathbf{q})\,\mathbf{a},
\qquad
\mathbf{f} := \mathbf{J}^{+}_{\lambda}\dot{\mathbf{x}},\quad
\mathbf{G} := a_{\max}\,\mathbf{B},
\end{equation}
with the task condition $\mathbf{c}$ entering $\mathbf{f}$ and $\Omega$ as a
fixed parameter.\xinyi{这句话很绕呀} Writing $r(\mathbf{q}) \ge 0$ for the instantaneous advance
rate along $\mathbf{d}$, i.e., the continuous-time counterpart of the reward
defined in Section~\ref{sec:traj}\xinyi{不要提前引用后面的内容，务必注意逻辑连贯性。}, define the discounted progress value
\begin{equation}
\label{eq:value}
V(\mathbf{q}_{0}) \;=\; \sup_{\mathbf{a}(\cdot)}
\int_{0}^{\tau} e^{-\beta t}\, r(\mathbf{q}(t))\,\mathrm{d}t,
\end{equation}
where the supremum runs over measurable commands into $\mathcal{A}$ and $\beta>0$ matches the implementation's discount. On the straight-line family the task term holds the advance rate at $v$, so $V$ increases with the exit time alone: the discounted problem is a maximum-exit-time problem. $V$ in (\ref{eq:value}) is the optimal value; the learned components of this paper approximate values of \emph{policies}. The analysis below uses only two facts: the dynamics (\ref{eq:affine}) are affine in $\mathbf{a}$, and the advance rate $r$ does not depend on $\mathbf{a}$ because $\mathbf{J}\mathbf{B}=\mathbf{0}$ holds exactly. What separates the exit-time form from instantaneous null-space optimization is only the argument of the maximization: a command at $\mathbf{q}$ is judged by how it changes all future feasible progress through $V$, rather than by any quantity evaluable at $\mathbf{q}$ in isolation.\xinyi{这一段毫无信息量，到底想表达什么。}


\subsection{Vertex-Valued Feedback}

The value function in (\ref{eq:value}) measures the discounted feasible
progress obtainable from the current configuration under optimal future
control. To turn this long-horizon quantity into a local feedback rule, we
use the Hamilton--Jacobi--Bellman (HJB) equation, the continuous-time form of
Bellman's optimality principle. It relates the current value to the
instantaneous progress and to the change of future value induced by the
system dynamics. At points where $V$ is differentiable, the discounted
exit-time problem satisfies
\begin{equation}
\label{eq:hjb}
\beta V \;=\; r \;+\; \nabla V^{\!\top}\mathbf{f}
\;+\; \sup_{\mathbf{a}\in\mathcal{A}}
\bigl(\mathbf{G}^{\!\top}\nabla V\bigr)^{\!\top}\mathbf{a},
\qquad V \equiv 0 \ \text{outside } \Omega .
\end{equation}
Since $r$ and $\mathbf{f}$ are independent of $\mathbf{a}$, the command
appears only in the last term and enters it linearly. Define the
\emph{switching vector}
\begin{equation}
\label{eq:sigma}
\boldsymbol{\sigma}(\mathbf{q}) \;:=\;
\mathbf{G}(\mathbf{q})^{\!\top}\nabla V(\mathbf{q}) \;\in\; \mathbb{R}^{m},
\end{equation}
whose $i$-th component measures how motion along the $i$-th null-space
direction changes discounted future feasible progress. The supremum in
(\ref{eq:hjb}) is therefore $\|\boldsymbol{\sigma}\|_{1}$ and, whenever no
component vanishes, is attained at the vertex
$\mathbf{a}=\operatorname{sgn}\boldsymbol{\sigma}$. Thus the value-based
resolution selects the orthant of the null-space command rather than its
magnitude.

This vertex structure is not specific to the optimal value $V$. The same
argument applies to the gradient of any differentiable scalar field, allowing
the feedback form to be used with an approximate value estimate.

\begin{proposition}
\label{prop:vertex}
Let $W:\Omega\to\mathbb{R}$ be differentiable and
$\boldsymbol{\sigma}_{W} := \mathbf{G}^{\!\top}\nabla W$. Then, at every
$\mathbf{q}$,
\begin{equation}
\label{eq:prop}
\max_{\mathbf{a}\in[-1,1]^{m}} \boldsymbol{\sigma}_{W}^{\!\top}\mathbf{a}
\;=\;
\max_{\mathbf{a}\in\{-1,1\}^{m}} \boldsymbol{\sigma}_{W}^{\!\top}\mathbf{a}
\;=\; \|\boldsymbol{\sigma}_{W}\|_{1},
\end{equation}
attained at $\mathbf{a}=\operatorname{sgn}\boldsymbol{\sigma}_{W}$, with the
components on which $\sigma_{W,i}=0$ chosen arbitrarily in $\{-1,1\}$.
Consequently, a greedy policy with respect to any differentiable value
estimate can be chosen vertex-valued: the vertex action space is closed under
policy improvement.
\end{proposition}

\begin{IEEEproof}
$\boldsymbol{\sigma}_{W}^{\!\top}\mathbf{a}
= \sum_{i}\sigma_{W,i}\,a_{i} \le \sum_{i}|\sigma_{W,i}|$ for
$\mathbf{a}\in[-1,1]^{m}$, with equality iff
$a_{i}=\operatorname{sgn}\sigma_{W,i}$ on every component with
$\sigma_{W,i}\neq 0$; such an $\mathbf{a}$ can be chosen in
$\{-1,1\}^{m}$.
\end{IEEEproof}

\begin{remark}[Scope]
\label{rem:bangbang}
Three qualifications delimit this result. First, the box- and
vertex-constrained problems share the same pointwise Hamiltonian by
(\ref{eq:prop}); equality of their value functions would require viscosity
comparison conditions that we neither verify nor use. Second, when a component
of $\boldsymbol{\sigma}$ vanishes, an optimal vertex-valued selector exists,
rather than every optimal command being a vertex. Third, the reduction is
exact in continuous time; its finite-rate consistency is examined empirically
in Section~\ref{sec:setup}, while the command box itself remains a design
choice.
\end{remark}

This structure is the kinematic counterpart of a classical result in
time-optimal path following: with control-affine dynamics and box-bounded
torques, the optimal acceleration lies on the boundary of the admissible set
except on singular arcs~\cite{bobrow1985time,shin1985minimum}.


\subsection{From the Classical Law to the Analytic Margin Law}
\label{sec:relation}
The classical secondary command of Eq.~(\ref{eq:secondary}) performs gradient
ascent on a weighted instantaneous objective; writing that objective, gains
and $a_{\max}$ absorbed, as $\Phi(\mathbf{q})$, the two laws read, in the
shared basis and up to scaling,
\begin{equation}
\label{eq:cl-vs-opt}
\mathbf{a}_{\mathrm{cl}}(\mathbf{q})
= \operatorname{clip}\bigl(\mathbf{G}^{\!\top}\nabla\Phi(\mathbf{q})\bigr),
\qquad
\mathbf{a}^{*}(\mathbf{q})
= \operatorname{sgn}\bigl(\mathbf{G}^{\!\top}\nabla V(\mathbf{q})\bigr).
\end{equation}
They differ in exactly two substitutions: the scalar field ($\Phi$ a hand-designed surrogate at the current configuration, $V$ the discounted future feasible progress) and the use of the gradient (the classical law keeps its magnitude, so the command shrinks where the surrogate is flat; the value-based feedback keeps only its sign).

$V$ itself has no closed form, and its domain, configurations crossed with task conditions, is far beyond the reach of grid-based HJB solvers. However, the exit-time structure indicates what the value gradient should attend to: on this family $V$ increases with the exit time alone, and the exit is caused by the first margin that reaches zero. This motivates replacing $V$ by the \emph{constraint-margin field}
\begin{equation}
\label{eq:margin-field}
\Phi_{\mathrm{m}}(\mathbf{q})
= -\tau_{\mathrm{m}} \log \sum_{j} \exp\bigl(-m_{j}(\mathbf{q})/\tau_{\mathrm{m}}\bigr),
\end{equation}
a soft minimum over the normalized joint-limit and orientation-cone margins
$m_{j}$, i.e., the constraints whose exhaustion terminates strokes. The
deployed training-free law is the vertex law of
Proposition~\ref{prop:vertex} applied to this field,
\begin{equation}
\label{eq:margin-law}
\mathbf{a}_{\mathrm{m}}(\mathbf{q})
= \operatorname{sgn}\bigl(\mathbf{G}^{\!\top}\nabla\Phi_{\mathrm{m}}(\mathbf{q})\bigr),
\end{equation}
optionally in its finite-rate form, where the $2^{m}$ vertices are scored
by $\Phi_{\mathrm{m}}$ one held command ahead (see
Remark~\ref{rem:bangbang} for the finite-rate gap). Relative to the
classical law, this law reverses
both substitutions of (\ref{eq:cl-vs-opt}): the field measures proximity to
\emph{all} exits jointly, and the sign keeps full authority where the field
is flat. It has no trained parameters and no per-manipulator gains.

\subsection{From the Margin Field to a Learned Value Field}
\label{sec:vlook}
The margin field only evaluates the \emph{current} configuration: a configuration may stand far from every limit and still be tens of increments from an unavoidable exit. The field that measures how long the exits can be deferred is the value function itself, and an estimate of it already exists wherever a reinforcement-learning baseline has been trained: the critic of an actor--critic run regresses precisely the discounted future progress of Eq.~(\ref{eq:value}) under its own improving policy. Reading that critic $\widehat{V}$ through the same finite-rate law gives the third member of the family,
\begin{equation}
\label{eq:value-law}
\mathbf{a}_{V}(\mathbf{q})
= \arg\max_{\mathbf{a}\in\{-1,1\}^{m},\; F(\mathbf{q},\mathbf{a})\in\Omega}
\widehat{V}\bigl(F(\mathbf{q},\mathbf{a})\bigr),
\end{equation}
where $F(\mathbf{q},\mathbf{a})$ is the exact one-step flow of
Eq.~(\ref{eq:affine}) under the held command and the feasibility test
discards vertices whose successor leaves $\Omega$. This is the finite-rate
finite-difference reading of $\operatorname{sgn}(\mathbf{G}^{\!\top}\nabla
\widehat{V})$, and its form is that of one policy-improvement step computed
at deployment time: for the \emph{exact} value of a policy, the greedy
policy is guaranteed not to be worse than that policy. The deployed critic
is an approximation learned from finite data, so this guarantee motivates
the construction rather than certifies it; whether the approximate critic
is accurate enough is answered empirically in Section~\ref{sec:setup}. In
implementation the critic input is the full policy observation, i.e.,
$\widehat{V}\bigl(\mathbf{o}(\mathbf{q},\mathbf{c},\mathbf{a})\bigr)$, where
the candidate command occupies the previous-action slot of the successor
observation.

Two properties make this consumption of a learned value reliable where a learned \emph{policy} is not. First, by Eq.~(\ref{eq:cl-vs-opt}) the optimal action \emph{is} a derivative of the value, and approximating a function well does not bound the error of its derivative; moreover, the critic receives a regression target at every state, while the policy gradient must extract the difference between the best and the second-best action from returns whose variance exceeds that difference by orders of magnitude. Second, Eq.~(\ref{eq:value-law}) never asks the network for a derivative: the exact model converts the action discrimination into a comparison of $2^{m}$ distinct states, in which the smooth approximation errors at neighbouring successors largely cancel. Section~\ref{sec:setup} tests every link of this argument.
}

\subsection{Task-Constrained Joint Trajectory Generation}
\label{sec:traj}
\new{This stage generates the trajectory incrementally, since neither the horizon nor the number of decision variables is known before the problem is solved: the quantity being maximized is the length at which the trajectory ends. At each increment the end-effector advances a fixed arc length, imposing Eq.~\eqref{eq:pos_constraint} increment by increment so that deviation never accumulates, and the redundancy is resolved in the null space of the position Jacobian. The only design choice is the null-space command $\mathbf{u}$.}



\new{At each increment, the $2^{m}$ vertices of the command box are
advanced one held command ahead by the exact model, infeasible successors
are discarded, and the survivors are scored by the deployed scalar field,
namely the margin field of Eq.~(\ref{eq:margin-law}) when no training is
available and the learned value field of Eq.~(\ref{eq:value-law}) when a
critic exists; the maximizer is executed. Both laws cost the same $2^{m}$
successor evaluations per increment. On the curved members of the path
family, the task term additionally carries a lateral feedback that holds
the tool inside the tolerance tube of Eq.~\eqref{eq:pos_constraint}; this
feedback is inert on straight rays.}

Every resolution law outputs an $m$-dimensional command $\mathbf{a}\in[-1,1]^{m}$ in a task-aligned null-space basis $\mathbf{B}(\mathbf{q})$, constructed by Gram--Schmidt inside the exact null space of the position Jacobian: the three projected objective gradients of Eq.~\eqref{eq:secondary} are orthonormalized first, and the orthogonal complement completes the basis. The command $\dot{\mathbf{q}}_{\mathrm{null}}=\mathbf{B}(\mathbf{q})\,(a_{\max}\mathbf{a})$ is added to the same task term for every law, so all laws \new{share one parameterization and are interchangeable at any increment}.

\new{\paragraph*{Learned baseline policies} The experiments compare the deployed laws against policies trained with Proximal Policy Optimization (PPO) under identical conditions, over the continuous box and over its $2^{m}$ vertices with a categorical head.}
The observation exposes the normalized joint configuration and its square (making proximity to either limit directly visible), the task vectors $\mathbf{d}$ and $\mathbf{n}$, the tool axis with its cross and inner products with $\mathbf{n}$ (the orientation error relative to the cone), and the previous command; the end-effector position is excluded because deviation from the path is held inside the tolerance by the task term. \new{Their reward is the clipped per-step progress along $\mathbf{d}$, normalized by $v\,\Delta t$, with no terminal penalty, so the return approximates the survival time and the trained policy pursues exactly the objective of Eq.~(\ref{eq:value})}. \new{A supervised variant of the vertex policy hands the increment to the classical law inside a thin boundary shell on the normalized joint-limit distance, with hysteresis $(0.98,0.94)$ fixed by a sweep; because all laws share the basis and task term, the end-effector increment is unchanged at a switch.}

\new{\label{sec:division}The division of labor behind this design is supported by direct measurement. Learning resolves \emph{states}: a value network regressing stroke outcomes reaches $R^{2}$ above $0.9$, and candidate starts spread by hundreds of millimeters. Learning does not resolve \emph{actions}: the $2^{m}$ vertices differ in one-step margin only by $5\times10^{-3}$ to $2\times10^{-2}$, direct best-vertex classification attains $24.7\%$ held-out accuracy, and none of seven probe parameterizations ($\gamma$-swept and margin-shaped PPO $1.37$--$1.45$, fitted value iteration $1.12$--$1.25$, one-step argmax classification $0.93$) beats the free analytic gradient. The exact model closes exactly this gap by converting the action discrimination into a comparison of distinct states; the actor--critic decomposition of Section~\ref{sec:ladder} exhibits both halves inside one training run.}

\subsection{Initial Joint Configuration Selection}
\label{sec:select}
For many tasks the achievable path length is largely determined before motion begins: a fixed end-effector pose leaves a one-dimensional self-motion manifold whose branches share the pose yet differ sharply in reachable path length. \new{This structure, and its consequence for redundancy resolution, are long established: null-space techniques cannot leave the manifold they start on~\cite{burdick1989characterization}, and joint limits split the manifold into disconnected branches~\cite{luck1993self,shimizu2008analytical}. One clarification is needed here: the task pins only the tool position and constrains the orientation by an inequality, so the candidates span the connected components of the task-feasible configuration set at the starting point, of which fixed-pose self-motion-manifold branches are the fully constrained special case. We keep the shorter word \emph{branch} throughout. What this paper adds is not the structure but a measurement of its magnitude (Section~\ref{sec:setup}).}

Therefore, this selection module aims to provide \new{the trajectory generation stage} with an initial joint configuration within a favorable branch. \new{The candidate layer must supply coverage of the branches, not precision: the IKSel table~\cite{yuan2026iksel} is queried along $N_{\mathrm{dir}}$ cone directions, reranked by the full Jacobian metric, refined, and reduced to $K$ candidates by farthest-point selection. The achieved length saturates in branches reached and is insensitive to per-candidate refinement.}

\new{Which candidate to start from cannot be read off any instantaneous geometric quantity, because the consequence becomes visible only at the end of the stroke. The selector is therefore supervised by the outcome itself: every candidate of every training task is rolled out under the deployed law, and the stroke lengths serve as the regression targets. Relabeling for a new manipulator, path family, or deployed law amounts to one batch of rollouts.}

\new{The score is permutation-equivariant over the candidate set: each candidate is encoded together with a mean-pooled context of the others and trained with a listwise ranking loss. The score is further conditioned on the task through a \emph{road table}, the path ahead sampled at fixed arc lengths, which makes the architecture applicable to every path family of Section~III; whether the tested distributions require this input is examined in Section~\ref{sec:ood}. Deployment costs one table query, one forward pass, and one refinement; no candidate is rolled out at deployment time.}

\subsubsection{Manipulator Base Placement}
\label{sec:place}

Continuous kinematic reachability also provides a task-aware criterion for
manipulator base placement. For each candidate base pose, the required path is
transformed into the robot frame and evaluated by the proposed framework. A
base pose is considered feasible when the complete path can be covered by a
single continuous stroke.

Unlike waypoint-wise reachability, this criterion accounts for the continuity
of the joint trajectory and the initial configuration branch. It therefore
identifies base poses from which the required path is continuously executable,
rather than merely pointwise reachable.

%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
\section{Conclusions and Future Work}
\label{sec:conclusion}
%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%%
In this paper, we introduced \textit{continuous kinematic reachability} to
measure how much of a manipulator's pointwise reachable path can be realized
by a single continuous stroke. We evaluated this quantity across three
manipulators and a distribution of tasks using the executed stroke and a
numerical pointwise-reachability reference.

The proposed framework follows a simple principle: learning provides
long-horizon state evaluation, while the exact model resolves fine local
action differences. The exit-time formulation and HJB analysis lead to a
vertex-valued redundancy-resolution law, through which the learned critic
consistently outperforms both the corresponding policy head and the
training-free baselines. Initial configuration selection follows the same
principle by learning to rank candidate branches from rollout outcomes.

The same framework also provides a task-aware criterion for manipulator base
placement. Future work will extend the formulation to dynamic constraints and
paths specified online.
