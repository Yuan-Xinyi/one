# 曲线扩展：结论、训练配方、原理

2026-08-08。所有数字都是同一批任务上对经典零空间律的比值，绝对行程不报告。
每个单元格里的经典臂都在同一个环境中重算，因此比值是配对的。
共 7 次 3000 万步训练、22 次 2048 任务评测、3 次切换率测量。

---

## 0. 结论

**在曲线上，决定性能的是动作空间，不是训练配方。**

蛇形任务族合并，与经典律的比值（能取两个种子的都已按种子平均）：

| 配置 | RL 臂 | 混合臂 |
|---|---|---|
| 顶点动作 + 直线训练 | **1.3680** | **1.4123** |
| 顶点动作 + 曲线训练（曲率盲） | 1.3485 | **1.4127** |
| 顶点动作 + 曲线训练（曲率可见） | 1.3359 | 1.3960 |
| 连续动作 + 曲线训练 | 1.2608 | 1.3034 |

三个因素放在同一把尺子上（同配置两次训练的散布是 **±0.03**）：

| 因素 | RL 臂 [95% CI] | 混合臂 [95% CI] | 判定 |
|---|---|---|---|
| A 曲率观测（盲 − 可见） | +0.0125 [−0.0110, +0.0363] | +0.0167 [−0.0046, +0.0383] | **噪声** |
| B 训练任务族（直线 − 曲线） | +0.0195 [−0.0048, +0.0436] | −0.0005 [−0.0223, +0.0201] | **噪声** |
| **C 动作空间（顶点 − 连续）** | **+0.0751 [+0.0529, +0.0978]** | **+0.0926 [+0.0721, +0.1136]** | **成立** |
| C′ 同上，取最好的顶点配置 | +0.1071 [+0.0803, +0.1352] | +0.1089 [+0.0855, +0.1330] | 成立 |

**实用结论：曲率不需要进训练分布，也不需要进观测。**
用直线配置训练顶点策略，直接部署到蛇形路径即可。
理由不是它更好，而是它不比任何替代方案差，同时省掉一个任务族、
一个观测通道和一次训练。真正要守住的是顶点动作空间。

## 1. 任务族是怎么定义的

蛇形路径 `y = A·sin(2πx/λ)`，起点在原点，沿 x 轴向远处延伸（不是闭合曲线）。

采样的是**摆角**而不是 (A, λ)：

```
swing ~ U[0, 30°]          # 行进方向相对轴线的最大偏摆
λ     ~ U[0.4, 1.2] m
A     = λ·tan(swing) / 2π
```

三个理由：

1. 对机械臂来说"难"的是**行进方向摆得多远**，不是振幅本身。直接采摆角，
   难度分布是显式的；分别采 A 和 λ，难度分布是隐式的。
2. `swing = 0` 就是直线。**直线是这个族的成员，不是单独的特例**，
   所以同一份代码、同一份配置既能训直线也能训曲线。
3. 拒绝 `κ_max = A(2π/λ)² > 1/0.15 m⁻¹` 的样本。比这更弯的波在第一个弯道
   就死，不携带学习信号。重抽的是摆角不是波长，这样波长保持均匀。

另外两处必须跟着改的地方：

- **进度沿轴测量**，`Δp·d₀`，不是沿弧长。否则策略会因为横向摆动本身拿到奖励。
- **`k_lateral = 5.0`**（直线配置里是 0）。纯前馈沿瞬时切线会切内角，
  横向误差随曲率累积，不加横向反馈会撞上横向误差终止条件。

`observe_curvature` 是可选的：打开就在观测里加一个通道，
即当前点的有符号曲率乘 `CURV_SCALE = 0.25`，观测维度 31 → 32。

## 2. 曲线为什么难——机理

两个来源，且只有一个是新的：

1. **特解本身在动。** 直线上 `ẋ` 方向恒定，`J⁺ẋ` 把构型往一个固定方向推。
   曲线上切线方向来回转，`J⁺ẋ` 也跟着转，所以**即使零空间命令恒为零，
   构型也被路径本身推着扫过一片区域**。这是曲率带来的真正新东西。
2. **跟踪误差。** 弯道切内角，靠 `k_lateral` 补。这一项是任务控制器的事，
   不是零空间的事；调好之后横向误差终止在三个臂上都只有 10–12%，
   说明它没有变成瓶颈。

关键的是**姿态约束不随路径转**：`n_target` 是每个任务固定的一个方向，
锥是绕它的。所以弯道对机械臂提的是**位置**上的额外要求，不是姿态上的。

这一点有数据支持。终止原因的分布，直线 vs 曲线，几乎不动：

| 臂 | 任务族 | 碰撞 | 锥角 | 关节限位 | 横向 |
|---|---|---|---|---|---|
| 经典 | 直线 | 0.8 | **81.4** | 8.8 | 8.9 |
| 经典 | 蛇形 | 0.9 | **81.0** | 8.6 | 9.5 |
| RL（直线训练） | 直线 | 3.2 | 58.3 | 26.2 | 12.2 |
| RL（直线训练） | 蛇形 | 3.1 | 58.6 | 26.3 | 12.1 |

**失效机制没变，只是行程被缩短了。** 这正是为什么直线上学到的零空间策略
可以直接搬到曲线上：它要解决的问题是同一个问题。

## 4. 三因素拆解与噪声底线

### 噪声底线：同一配置跑两次

同配置的完全重复（同任务池，只有网络初始化与采样随机性不同），蛇形族合并：

| 配置 | 臂 | 两次运行之差 | 95% CI |
|---|---|---|---|
| 直线配置 | RL | +0.0040 | [−0.0244, +0.0328] |
| 直线配置 | 混合 | +0.0041 | [−0.0208, +0.0291] |
| 曲线配置 | RL | −0.0249 | [−0.0538, +0.0041] |
| 曲线配置 | 混合 | −0.0137 | [−0.0395, +0.0118] |

**噪声底线是 ±0.03**（单次运行对单次运行，95% 区间半宽）。

最直观的一格：曲率可见的曲线策略，两个种子在 10–20° 桶上是 1.3069 和 1.3577，
**差 0.051**。种子 1 偏低那一次，正是"曲线训练更差"这个表象的来源。

### 三个因素

逐任务差值是重尾的，均值会被尾部带走，所以必须同时看中位数与胜率。
均值和中位数不一致，说明效应集中在尾部而非普遍存在。

| 因素 | 臂 | 均值差 [95% CI] | 中位数差 | 胜率 | 判定 |
|---|---|---|---|---|---|
| **A 曲率观测**<br>盲 − 可见 | RL | +0.0125 [−0.0110, +0.0363] | −0.0014 | 46.9% | **无效应** |
| | 混合 | +0.0167 [−0.0046, +0.0383] | −0.0000 | 46.2% | **无效应** |
| **B 训练任务族**<br>直线 − 曲率盲 | RL | +0.0195 [−0.0048, +0.0436] | +0.0035 | 55.7% | 噪声内 |
| | 混合 | −0.0005 [−0.0223, +0.0201] | +0.0020 | 54.2% | 噪声内 |
| **C 动作空间**<br>顶点 − 连续 | RL | **+0.0751 [+0.0529, +0.0978]** | +0.0156 | 63.0% | **成立** |
| | 混合 | **+0.0926 [+0.0721, +0.1136]** | +0.0132 | 63.2% | **成立** |

- **A 的均值与中位数反号，胜率低于 50%**：曲率盲策略在更少的任务上获胜，
  只是赢的时候赢得多。这是"没有系统性效应"的形状。
- **B 在混合臂上是 −0.0005**，两个配置实质相同（1.4123 vs 1.4127）。
- **C 在三个摆角桶上全部显著**（RL +0.0752 / +0.0643 / +0.0474，
  混合 +0.1000 / +0.0772 / +0.0794，六个区间无一含零），
  量级是噪声底线的 2–3 倍，且方向与直线上独立得到的结论一致。

## 5. 训练配方（如何训练曲线）

**推荐：不专门训练曲线。** 用直线配置训练，直接部署到曲线。

### 5.1 训练

```
python -m Yuan.IJRR.stage2_traj.train \
    --config Yuan/IJRR/stage2_traj/config_vertex_line.yaml \
    --out-dir Yuan/IJRR/runs/<name>
```

关键项：`agent.kind = vertex`（16 顶点分类策略）、`observe_curvature = false`、
不设 `swing_max_deg`、3000 万步、单卡约 1.5–1.7 小时。

### 5.2 部署到曲线：只改环境，不改策略

策略维度不变（31 维），因为它不看曲率。环境侧改三处：

```yaml
env:
  k_lateral: 5.0            # 必需，否则弯道切角撞上横向误差终止
line_distribution:
  swing_max_deg: 30.0
  wavelen_range: [0.4, 1.2]
  min_radius_m: 0.15
```

混合层不变：τ_enter = 0.98，τ_exit = 0.94，滞回作用在 `max|q_norm|` 上。

### 5.3 若仍要在曲线上训练

用 `config_vertex_curve_noobs.yaml`（曲线分布、**不给曲率观测**）。
它在混合臂上与直线训练打平（1.4127 vs 1.4123）。
`config_vertex.yaml`（给曲率观测）在两个臂上都略低，不推荐。

### 5.4 评测

```
python -m Yuan.IJRR.eval.eval_curve \
    --config Yuan/IJRR/stage2_traj/config_vertex.yaml \
    --ckpt <run-dir> --n-tasks 2048 \
    --swing-max-deg {0|30} --observe-curvature {0|1}
```

`--swing-max-deg` 与 `--observe-curvature` 是这次新加的覆盖开关。两者都
**不改动力学**：曲率通道只进观测，摆角上限只属于任务分布。正因如此，
一个 31 维的直线策略才能在曲线任务上被打分，且与 32 维策略共享同一条
经典基线。`--k-lateral` 也加了，但它**会**改闭环，只用于 §7 的惰性检验。

切换率：
```
python -m Yuan.IJRR.eval.switching_rate --config <cfg> --ckpt <run-dir> \
    --n-tasks 2048 --swing-max-deg {0|30} --observe-curvature {0|1}
```

## 6. 原理

### 6.1 为什么曲率不必进训练分布，也不必进观测

策略解决的问题是：给定当前构型和当前的任务空间速度需求，往零空间的哪个方向
推，才能把"离约束边界还有多远"这件事维持得最久。

- 这个问题的**输入是当前状态**，不是路径的全局形状。
- 曲率对它的影响，只是让下一步的任务空间速度方向跟这一步不同。而任务空间
  速度方向本来就随任务变化（每个任务的 `line_dir` 和 `n_target` 都是随机的），
  策略在直线族上已经见过各种方向组合。
- 所以曲线对策略而言不是新问题，**是同一个问题的一个新序列**。

两个可检验的预测，都被 §4 证实：

- **训练任务族无所谓**——两个族在策略看到的状态空间里重叠，
  曲线只是把同一批状态按另一个顺序串起来。测得 B 在噪声内。
- **曲率观测无所谓**——它是路径的属性，不是"当前状态离约束边界多远"的属性，
  不进入决策。测得 A 在噪声内，且中位数反号。

§2 的终止原因表是同一句话的另一个侧面：失效机制在两个任务族上是同一个。

**反过来说，如果曲率观测有用，就说明零空间决策依赖路径的全局形状，
6.1 就错了。** 这一节不是"没测出差别"，是一个预测被证实。

### 6.2 为什么动作空间反而是决定性的

动作空间不改变策略要解的问题，它改变**梯度能不能传回去**。连续版要输出 ±1，
就得把 tanh 之前的 μ 推得很大，而梯度回传要乘 `1 − tanh²`，这个因子在饱和处
接近零，学习信号被掐断。顶点版的 logits 直接对应"选哪个顶点"，没有这一层衰减。

这解释了它为什么是唯一稳健的效应：它作用在**优化**上，
而任务族和观测通道作用在**问题定义**上——按 6.1，问题定义本来就没变。

### 6.3 为什么混合臂上因素 A、B 的差距更小

混合在 `max|q_norm| ≥ 0.98` 时交给经典律，回到 0.94 以下再交还。
关节限位是 RL 臂在曲线上的主要死因（26–28%，经典律只有 8.6%），
混合把这一项压到 15.7%。两个策略的差别主要发生在接近限位的那一段，
而那一段正是混合交给经典律的，所以差别被吸收了。
因素 C 的差距大到混合吸收不掉，这也是它稳健的一个旁证。

### 6.4 顶点动作空间在曲线上的理论前提

松弛定理（Filippov–Ważewski）保证顶点值命令生成的轨迹在箱值命令生成的轨迹中
稠密，**前提是切换足够快**。直线上实测等效切换 16.3 Hz 对 20 Hz 控制率，
预算几乎用满，所以"弯道会不会把这点余量吃掉"是一个真问题。

实测结果：**不会。**

| 策略 | 任务族 | 0–10° | 10–20° | 20–30° | 总体 |
|---|---|---|---|---|---|
| 直线训练 | 直线 | — | — | — | 16.3 Hz |
| 直线训练 | 蛇形 | 16.0 | 16.1 | 16.2 | 16.1 Hz |
| 曲线训练 | 蛇形 | 16.2 | 16.5 | 16.6 | 16.4 Hz |

切换率在三个摆角桶上基本平坦（随摆角上升不到 0.4 Hz），
中位停留仍是 0 步、无变化的步数占 18–20%。
**曲率不消耗切换预算**，所以松弛定理的前提在曲线上和直线上同样成立。

## 7. 混淆项的处理

直线策略与曲线策略之间原本差三样东西，逐个交代：

1. **训练任务族**——因素 B，已隔离，在噪声内。
2. **曲率观测通道**——因素 A，由 `rl_vertex_curve_noobs_30M` 隔离，在噪声内。
3. **训练时的 `k_lateral`**（直线配置 0，曲线配置 5.0）。**已验证是惰性的**：
   直线策略在直线任务上，`k_lateral = 0` 得 RL 1.3891 / 混合 1.4300，
   `k_lateral = 5` 得 1.3994 / 1.4347，差 0.010 / 0.005，都在噪声底线内。
   直线路径上横向误差本来就接近零。在曲线任务上这个混淆是**不利于**直线策略的
   （它没在这个闭环下训练过），而它仍然不落下风。

## 8. 未决事项与 caveats

1. **连续动作臂只有一次运行**，没有重复种子。因素 C 的量级是噪声底线的
   2–3 倍且三桶一致，但严格说它是"2 种子顶点对 1 种子连续"。
2. **曲率盲配置只有一次运行**，因素 A 同样是 1 对 2 种子。
3. **正弦波的曲率可以从位置光滑推断。** 如果换成曲率突变的路径族
   （分段圆弧、拐角），"看不到曲率"与"看到曲率"的信息差会变大，
   §6.1 的第二个预测可能不成立。这一条没有测。
4. **摆角上限 30°、最小曲率半径 0.15 m、`k_lateral = 5.0`** 是设计选择，
   没有做敏感性分析。
5. **任务池缓存键不含 `k_lateral`。** 可行性过滤用的经典控制器受它影响，
   但缓存键里没有它，所以同一个池子会被不同 `k_lateral` 的运行复用。
   对本报告没有影响（所有单元格共享同一个池子，这正是配对所需要的），
   作为一致性缺口记在这里。
6. 主表的 C0 是否换成顶点策略仍未决；换了要重打 stage-1 的选择器标签。
