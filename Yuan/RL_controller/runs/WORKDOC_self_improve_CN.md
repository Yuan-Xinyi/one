# Self-Improvement 工作文档：思路来源、方法借鉴与结论

（面向不熟悉本工作的读者；2026-07-02 ~ 07-03 完成，配套数字报告见 `REPORT_0703.md`）

---

## 1. 背景与问题设定

本项目的控制系统里有两个"老师傅"：

- **π₀（RL 策略）**：用 PPO 训出的单一神经网络控制器，在大多数任务上比 classical 控制器走得更短（10k 评估集上 L_pure/L_oracle = 0.990）。
- **Classical 控制器**：手工设计的局部梯度控制律。它在"危险带"（关节接近限位，`max|q_norm| ≥ 0.98`）里有 π₀ 不具备的**救援能力**——π₀ 一旦进入危险带常常几步内死亡，而 classical 能把机械臂拉回来。

此前的最优方案是**混合系统（hybrid）**：跑 π₀，一旦进入危险带就切换到 classical，成绩 **1.0503**。它的缺点是：需要在线切换逻辑、两套控制器共存，且切换阈值是手工调的。

**本工作的目标**：让一个单一网络学会混合系统的全部本领，在 10k 评估集上追平甚至超过 1.0503。换句话说：π₀ 能不能"自我改进"，把 classical 的救援技能内化进自己的权重里？

**评估口径**（全文一致）：逐任务 `L / L_oracle` 的均值，其中 oracle 是 classical-controller-optimal 标签（注意它不是真正的性能上限，只是 classical 控制器下的最优起点标签）。只报告比值，不报告绝对长度或成功率——因为部分任务本质不可行，绝对指标无意义。

## 2. 思路来源与我们的借鉴方式

这项工作不是单一算法，而是把若干经典思想串成一条流水线。每个来源工作、它的核心思想、以及我们如何改造，逐一说明如下。

### 2.1 Expert Iteration (ExIt) —— 整体框架的来源

**来源**：Anthony et al., *Thinking Fast and Slow with Deep Learning and Tree Search* (NeurIPS 2017)；同思想也是 AlphaGo Zero 的骨架。核心：维护一个"慢而强的专家"（搜索 + 当前策略）和一个"快而弱的学徒"（神经网络），每轮用专家生成数据训学徒，学徒变强后专家（因为内含学徒）也变强，形成闭环迭代。

**我们的借鉴**：把 **hybrid 切换系统本身当作 policy-improvement operator**——

```
π_{k+1} = distill( hybrid(π_k, classical) )
```

hybrid(π_k) 严格不弱于 π_k（危险带里有 classical 兜底），所以每一轮蒸馏都在逼近一个更强的目标。收敛判据也随之自然定义：当 `frac(hybrid > pure) → 0`（切换不再带来收益），说明切换行为已被完全内化，operator "榨干"了。这一指标从 22.8% 一路降到 8.5%，是整个 campaign 的主进度条。

后期我们进一步把专家中的 classical 分支升级为 **MPC 搜索**（见 2.4），这就更贴近原版 ExIt "专家 = 搜索增强的策略"的形态。

### 2.2 Policy Distillation —— 内化的具体手段

**来源**：Rusu et al., *Policy Distillation* (ICLR 2016) 及后续 kickstarting 一系工作。核心：把一个（或多个）教师策略的行为用监督学习压进一个学生网络。

**我们的借鉴**：`self_improve/distill.py` 对**整张混合行为图**做纯监督蒸馏——安全区标 π₀ 的动作、危险带标 classical 的动作，学生是一个与 Agent 兼容的 512 宽 MLP。做这一步之前先做了**可行性诊断**：用监督拟合验证 classical 的救援动作场从 31 维观测是可表示的（R² = 0.907），确认瓶颈不在表示能力，而在 RL 的发现能力（见第 4 节结论 1）。

我们在实践中总结出蒸馏保真度的三个杠杆（重要性排序）：**warm-start（从上一轮学生热启动）≫ 软切换边界（在阈值附近宽 0.02 的带内混合两个教师，val MSE 0.019→0.0013）> 加大容量（1024 宽从零训反而更差）**。

### 2.3 DAgger —— 修分布漂移

**来源**：Ross et al., *A Reduction of Imitation Learning to No-Regret Online Learning* (AISTATS 2011)。核心：纯行为克隆的学生会在自己的轨迹上漂移出教师数据的分布；解法是让**学生自己跑**，再请教师在学生到达的状态上重新标注。

**我们的借鉴**：每轮蒸馏后跑 DAgger round——用当前学生 rollout，在其访问到的状态上请教师（后期是 MPC 教师，r9 用了 K=32 候选）标注，并入数据集。另有一条反面经验：**标注要用"血统教师"（lineage，即上一轮学生 + classical 组成的 hybrid），而不是回退到原始 π₀**——用 π₀ 给安全区标注反而拖低了学生的易题成绩（1.062 vs 1.070），因为 π₀ 的访问分布和学生已经不匹配。

### 2.4 MPC-guided training (Guided Policy Search 谱系) —— 突破教师天花板

**来源**：Levine & Koltun, *Guided Policy Search* (ICML 2013)，以及 MPC-GPS / MPC-Net 一系：用带前瞻的最优控制器当教师，把搜索的成果蒸馏进反应式策略。

**我们的借鉴与关键洞察**：纯 ExIt 蒸馏在 ~1.045 处触顶——**天花板是教师定的**，而教师危险带分支只是 classical 的局部梯度律，本身次优。于是 `self_improve/mpc_teacher.py` 用**确定性仿真器做精确前瞻搜索**替换这个分支：对危险带状态，尝试 K 个候选动作（classical 的、策略自己的、扰动、均匀采样），每个候选持有 10 步后接 classical 闭环走到终局，按精确折扣回报打分取 argmax。由于 classical 自己的动作永远在候选里，标签**保证不弱于 classical**。

先过验证门再上产线：搜索动作在危险带比 classical 平均好 **+8.6%**，94% 的最优动作来自搜索而非 classical 原动作——教师确实更强，才值得蒸。另一条工程结论：MPC 原始标签带搜索抖动（val MSE 地板 0.006–0.02），**只应在深危险带（qn ≥ 0.975）使用，其余区域仍用干净的 hybrid 标签合并**——全区套 MPC 标签会污染易题。

### 2.5 干预式模仿 / 安全网 RL —— 失败但出结论的一支

**来源**：HG-DAgger、intervention-based RL 一类"人/专家在环兜底"的思想：训练时让 classical 当安全网，策略犯险时接管救回来，期望策略在保护下学会危险带技能。

**我们的借鉴与失败发现**：guided switch-in-loop PPO——训练时保留切换，救援步的动作以 clipped-ratio 方式（z = atanh(a_cls)，log-ratio 钳位，V-trace 风格）注入 PPO。结果**严重失败**（训练到 51% 时 0.607），且失败机理很有普适性：**moral hazard（道德风险）**——救援是免费的、救援期间 progress reward 照发，策略学会了"倚赖安全网"而非"学会自救"，guide_frac（被接管的步数占比）从 0.13 涨到 0.36。这与经济学里保险导致风险偏好上升是同构的。

补救尝试：
- **课程退火**（per-episode Bernoulli 决定本集有无安全网，保护概率 1→0）：机械地消除了倚赖，但无保护的 episode 里策略学成了**回避危险带**而非掌握它，仍失败（0.644）。
- **Critic floor**（见 2.6）：guided 系里最大的单项增益（0.644→0.902），但完整 30M 预算下仍低于 vanilla π₀（0.990）——整条 guided 路线最终放弃。

### 2.6 Critic 下界约束 V ≥ V_cls —— 自创机制，思想上接近保守价值估计

**来源**：没有单一对应论文；思想根源是控制里的"可行策略给出价值下界"——classical 控制器**永远可执行**，所以任意状态都有 V*(s) ≥ V_cls(s)。这和 offline RL 里 CQL 一类"给价值函数加约束"的思路方向相反（他们压上界防高估，我们托下界防**写死**）。

**我们的做法**（`self_improve/vcls.py`）：环境是确定性批量仿真器，所以 V_cls 标签可以**精确**算出——从任意状态起跑 classical 到终局，累计折扣 progress return。采集 classical 和策略两种访问分布下的 159k 状态，精确标注后拟合小 MLP（保守分位数拟合 + margin，控制高估率在 1.5%）。PPO 时加辅助损失 `relu(V_cls(s) − V(s))²`，让 critic 不许"写死" classical 明明救得回来的状态——这样危险带里类 classical 救援动作的 advantage 保持为正，防止课程退火期的回避坍塌。**机制验证成立且可复用**，只是不足以单独救活 guided 路线。

### 2.7 Tanh-squashed 分布的真熵 —— 来自 SAC 的修正

**来源**：Haarnoja et al., *Soft Actor-Critic* (2018) 中对 tanh 压扁高斯的 log-prob 变换修正项。

**我们的发现**：旧 PPO 配方用未压扁 Normal 的熵做 entropy bonus，是**退化的**——最大化它只会把 σ 推到钳位上限 1.65（包括 π₀ 在内的所有历史 run 都如此，等效 bang-bang 探索）。按 SAC 的换元公式改成压扁后分布的真熵（ppo.py `squashed_entropy: true`）后，从零训练的难题成绩 0.687→0.856。这确认了旧配方的一个根因，但**纯 RL 在 30M 预算内仍然到不了顶**（见结论 1）。

### 2.8 Model Soups —— 最后白拿的一小步

**来源**：Wortsman et al., *Model Soups* (ICML 2022)：同一初始化微调出的多个模型做权重平均，常能免费涨点。

**我们的借鉴**：r8 和 r9 同属一条 warm-start 链（同盆地），直接权重平均得 `distill_soup2`，+0.001~0.002，成为最终交付的 π_final。

## 3. 实验路线与结果

按时间顺序（也是"排除法"的顺序——前四条失败路线的尸检直接催生了主线）：

| # | 路线 | 结果 (L_pure/L_oracle) | 一句话结论 |
|---|---|---|---|
| 1 | RL+BC ExIt ×4 轮（win-filter 蒸馏 + 联合 PPO） | 0.971（< π₀ 0.990） | BC 与 PPO 共 trunk 互噬 |
| 2 | Guided switch-in-loop PPO | 0.607（@51% 停） | moral hazard，倚赖安全网 |
| 3 | + 课程退火 | 0.644（@54% 停） | 机械脱依赖 ≠ 内化，学成回避 |
| 4 | + critic floor，完整 30M | 0.902 | 机制有效（+0.26）但整体仍败 |
| 5 | 熵修复后纯 RL 从零 | 难题 0.687→0.856，总分仍 < π₀ | 根因之一确认，但 RL 发现不了危险带技能 |
| 6 | 危险开局 + floor | 0.952 | 数据分流拖累易题，净负 |
| 7 | **蒸馏 ExIt（主线）** r1→r5(热启动)→r6(软边界) | 1.030 → 1.045 → 1.044 | 触及 classical 教师渐近线 ~1.045 |
| 8 | **+ MPC 教师** r7→r8(合并标签)→r9(DAgger)→soup2 | 0.970(难题) → 1.048 → 1.047 → **1.0492** | 教师升级突破天花板 |

**最终成绩**：

- **π_final = `runs/distill_soup2`**：10k 上 **1.0492**（难题 0.977 / 易题 1.070）。与混合系统胜负线 1.0503 差 0.0011，小于配对 SE ≈ 0.004 —— **单一网络在统计上追平了混合系统**；相对 π₀ (0.990) +6.0pp，难题层从 0.687 提到 0.977。
- **最优系统 = hybrid(distill_r8, τ=0.98 无滞回)**：**1.0615**，刷新系统纪录（旧纪录 1.0503，+1.1pp）——学生更强之后，再套一层切换仍有残余收益。
- **论文口径**（diffusion 种子 × pct of oracle′）：soup2 pure 88.6%，soup2+switch **90.9%**（原 Hybrid 行 90.6%）。
- **鲁棒性**：q0 扰动下与 π₀ 同衰减斜率，优势全程保持。
- `frac(hybrid > pure)`：22.8% → **8.5%**，切换行为接近完全内化。

**关于一条容易误读的对照**：guided 系在退火期 train-eval 从 0.25 恢复到 0.38 m，看起来像"课程起效了"——尸检表明那只是**从自己造成的伤害中恢复**，并未超过 baseline。难题层（π₀ 需要救援的那 22.8%）guided 最优变体只有 0.669，甚至低于 π₀ 自己的 0.687。

## 4. 验证了什么结论（可复用的机制性发现）

1. **危险带技能"可表示、可监督拟合（R²=0.91）、但不可被 PPO 发现、也不可被 PPO 保持"**。发现不了：危险带里从零策略几步内必死，advantage 是噪声比噪声，没有梯度信号。保持不住：从蒸馏好的 ckpt 做 PPO 微调，即使熵系数设 0，难题层也会被侵蚀（v1/v2 对照留档 `runs/pid_finetune_v1_eroded|v2`）。**结论：在这类"窄生存流形"问题上，蒸馏是技能迁移的唯一可用通道，RL 只适合在流形上做微调（且本例连微调都不行）。**
2. **Moral hazard 在 RL 安全网训练中真实存在且占主导**：免费救援 + 救援期发奖励 → 策略把安全网当作策略的一部分。任何"训练时兜底"的方案必须回答"如何计费"。
3. **Critic floor（V ≥ V_cls 精确下界）作为机制成立**：防止 critic 写死可救状态，是 guided 系最大单项增益，且基建可复用（159k 精确标注 + vcls.pt 已留存，未来做价值切换器可直接用）。
4. **教师质量即蒸馏天花板**：ExIt 蒸馏严格逼近教师渐近线（classical 教师 ~1.045）；要突破只能升级教师（MPC 搜索 +8.6% over classical）。反过来，坏标签（全区 MPC、π₀ 标安全区）会实打实拖低学生。
5. **蒸馏工程三杠杆**：warm-start ≫ 软边界 > 容量（负作用）；同链 model soup 白拿 +0.001~0.002。
6. **旧熵 bonus 退化**（Normal 代理 vs tanh 压扁真熵）：影响所有历史 run 的探索行为，已在 ppo.py 修复（默认关闭、向后兼容）。

## 7. 续篇（2026-07-03 下午）：两条建议路线执行完毕，SOTA 再次刷新

按第 6 节的优先级把前两条路线跑完，结果（细节见 `REPORT_0703.md` 续战章节）：

**新纪录：**
- **系统 1.0615 → 1.0669**（+0.54pp，3.9σ 显著）：新切换底座 = 用 K=32/hold=16 的高质量 MPC 深带标签、以 0.965 为合并边界蒸出的学生（`distill_r12m_b0.965_soup2`），配宽滞回阈值 τ=0.985/0.96；
- **单网 1.0492 → 1.0510**（名义新高，1.4σ）：`distill_soup3_s2_b975`，即 soup2 与新蒸馏学生的同盆地权重平均——首次名义反超旧混合系统线 1.0503；
- **论文口径 Hybrid 行 90.6 → 91.4%**（单网 pure 89.1%）。

**两个有普适价值的新结论：**
1. **深带边界的 pure/hybrid 最优点分裂**：更深的 MPC 标签（边界 0.965）让学生救援行为更早介入，作为切换底座更强，但伤单网 pure（易题路径税）；边界 0.975 则相反。最终交付因此是两个不同的网——"最好的独奏者"和"最好的乐队成员"不是同一个人。
2. **价值切换器被数据否决（而非想法错误）**：用 163k 状态的成对精确标注证明头寸真实存在（带内 35.3% 状态 classical 真值更优），但 V 网回归噪声（合成 RMSE 7.8）对信号幅度（std 10.5）信噪比不足，最优变体 1.0456 远低于 τ 切换的 1.0653。除非价值网 RMSE 降到 ~3，否则不必重试；成对数据集已留档可复用。

另有一条工程红利：宽滞回（0.985/0.96）在成绩微升的同时把切换次数从 0.84 降到 0.31 次/集，对真机部署更友好。
